# Business Overview

## Business Description

**システム名**: employee-profile-app（人材管理アプリ）

**目的**: 社員のプロフィール情報（氏名・部署・職種・スキル・稼働状況）を一元管理し、
人事担当者や管理者が社員情報を素早く参照・更新できるようにする。

**現在の状態**: フロントエンドのみ実装済み。バックエンド・認証・DB は未接続（モックデータ）。

## Business Transactions

| トランザクション   | 説明                                      | 実装状態     |
|----------------|------------------------------------------|------------|
| 社員一覧表示     | 全社員の基本情報をテーブルで一覧表示する       | 実装済み     |
| 社員詳細閲覧    | 特定の社員の詳細プロフィールを確認する         | スタブのみ   |
| 社員登録        | 新規社員情報を入力・登録する                 | スタブのみ   |
| 社員情報編集    | 既存の社員情報を更新する                     | スタブのみ   |
| 社員削除        | 社員情報を削除する (Redux 実装済み)          | UI 未実装   |
| 社員検索・フィルタ | キーワード/部署/スキル/ステータスで絞り込み | State のみ  |
| ダッシュボード閲覧 | 統計・サマリー情報を表示する               | スタブのみ   |

## Business Dictionary

| 用語           | 定義                                              |
|--------------|--------------------------------------------------|
| 社員           | 組織に所属するメンバー（正社員・契約・パート・インターン） |
| 部署           | 社員が所属する組織単位（例: 開発部、人事部）          |
| スキル         | 社員が保有する技術・資格・専門能力のリスト             |
| 稼働状況       | 現在の就業状態: active（稼働中）/ leave（休業中）/ retired（退職） |
| 雇用形態       | full-time / part-time / contract / intern          |
| プロフィール    | 社員の自己紹介・担当業務の説明文                     |
